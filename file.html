CyberPatriot Mint 21 Practice Round

A step-by-step guide to the scored tasks, security fixes, and penalties in the practice image.

Practice image only: Follow the README in your image, and review all forensics questions before making changes. Removing users, files, packages, or changing services can be destructive on a real computer.

1Find the MP3 directory — Forensics Question 1 (8 points)

  1. Read all forensics questions before modifying the image.
  2. Open a terminal with Ctrl + Alt + T.
  3. Update the file index: 
    sudo updatedb
  4. Search for MP3 files: 
    locate '*.mp3'
  5. The directory containing the files is /home/benjamin/Music.

2Remove unauthorized user tgianopolous (5 points)

  1. Check the README for the list of authorized accounts.
  2. Open Menu → Administration → Users and Groups.
  3. Select tgianopolous, choose Delete, and authenticate if prompted.
  4. Choose Delete Files if that is required by the practice image.

3Remove unauthorized user jquelling (5 points)

  1. In Users and Groups, select jquelling.
  2. Choose Delete, authenticate if prompted, then choose Delete Files if required.

4Make dscott a standard user (5 points)

  1. In Users and Groups, select dscott.
  2. Next to Account Type, choose Change… → Desktop User → OK.
  3. Authenticate to apply the change.

Correction: The pasted instructions say to select jquelling in this step, but the scored task is about dscott. Select dscott.

5Change llitt’s insecure password (5 points)

  1. In Users and Groups, select llitt.
  2. Choose Password → Change… and authenticate.
  3. Select Set password by hand.
  4. Enter a secure password of at least 12 characters in both password fields, then choose OK.

6Create administrator account edarby (6 points)

Open a terminal and run:

sudo adduser edarby
sudo usermod -aG sudo edarby

Follow the prompts to create the account and enter a password.

7Require edarby to change password at next login (6 points)

Run:

sudo passwd -e edarby

8Enable UFW firewall (6 points)

  1. Check its current status: 
    sudo ufw status
  2. Enable it in Menu → Control Center → Firewall Configuration, or run: 
    sudo ufw enable
  3. Authenticate if prompted.

9Disable or remove the FTP service (6 points)

Stop and purge vsftpd:

sudo systemctl stop vsftpd
sudo apt purge vsftpd

When asked to continue, enter y.

10Set updates to apply automatically (5 points)

  1. Open Menu → Control Center → Update Manager.
  2. Choose Edit → Preferences → Automation.
  3. Select Apply updates automatically and authenticate if prompted.

11Install available updates (5 points)

In Update Manager, refresh the list and choose Install Updates. Alternatively, run:

sudo apt update
sudo apt full-upgrade -y

Read any prompts about configuration files before responding. Keeping the local version is often safer when you are unsure, because replacing it can change service configuration.

12Update systemd, Chromium, and OpenSSH (5 points each)

Update the package list and upgrade installed packages:

sudo apt update
sudo apt full-upgrade -y

Review configuration-file prompts carefully. The practice key says the package maintainer’s version of the OpenSSH configuration is acceptable for this image, but that choice may differ in another competition image.

13Remove prohibited MP3 files (5 points)

  1. Find the files: 
    locate '*.mp3'
  2. Confirm they are prohibited by the README and are in the expected directory.
  3. For the files identified in this practice image, remove MP3s from the Music directory: 
    sudo rm /home/benjamin/Music/*.mp3

Path correction: The pasted command had a spacing error. The corrected path is /home/benjamin/Music/*.mp3. Double-check the path before running rm.

14Remove Wireshark and Zangband (6 points each)

After confirming these packages are not authorized by the README, run:

sudo apt purge -y 'wireshark*' 'zangband*'

15Disable SSH root login (6 points)

  1. Install the text editor if it is not already available: 
    sudo apt update
sudo apt install -y gedit
  2. Open the SSH server configuration with administrative permission: 
    gedit admin:///etc/ssh/sshd_config
  3. Change PermitRootLogin yes to PermitRootLogin no.
  4. Save the file and exit. Keep the OpenSSH service installed and available, as the README identifies it as critical.

!Penalties to avoid

  • VirtualBox: The image warns that VirtualBox is unsupported. Use the competition-specified version of VMware Workstation Pro.
  • OpenSSH stopped or removed: Avoid this; the README identifies OpenSSH as a critical service. Penalty: 5 points.
  • Chromium removed: Keep Chromium installed; the README identifies it as the required default browser. Penalty: 5 points.
